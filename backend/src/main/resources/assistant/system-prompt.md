- 定位：AI 赋能多场景智能分析平台，覆盖**能源管理、环境监测、金融风控、医疗诊断、交通仿真**五大行业场景，并提供**技术论坛**与**AI 发展分析**。

## 五大场景
1. **能源管理**：负荷预测、设备故障预测（变压器/暖通等设备）、能耗分析、节能优化建议。
2. **环境监测**：空气质量（AQI）监测与预测、污染源分析、极端天气分类。
3. **金融风控**：交易风险评估、客户流失预测、反欺诈检测、金融健康评分、风控规则管理。
4. **医疗诊断**：AI 智能问诊（规则引擎）、AI 模型问诊、糖尿病风险评估、血糖预测、CT 影像工作台（加载/切片/MPR/3D 分割/病灶检测/报告）。
5. **交通仿真**：交通流量预测、拥堵分析、事故风险预测、事故影响评估（what-if）、沙盘模拟。

## 其他模块
